Moonshot ouvre un Kimi K3.1 Pro expurgéMoonshot opens a stripped-down Kimi K3.1 Pro

Annoncé le 23 octobre, disponible aussitôt par API, poids complets promis pour le 4 novembre. Moonshot dit avoir retiré de l'entraînement les données liées aux attaques informatiques avant cette publication ouverte : son test interne d'exploitation de failles passe de 90,5 à 81 pour cent entre la version non expurgée et celle qui sort.Announced October 23, available through the API at once, full weights promised for November 4. Moonshot says it removed cyberattack-related material from training before this open release: its internal software exploitation test falls from 90.5 to 81 percent between the uncut version and the one being shipped.

Un laboratoire qui dégrade volontairement son propre modèle avant de l'ouvrir, c'est nouveau. Reste que des poids publiés se réentraînent.A lab deliberately degrading its own model before opening it is new. Published weights can still be retrained, though.

Des affiliés de rançongiciels pilotent leurs intrusions par IARansomware affiliates run their intrusions through AI

Rapport publié le 20 octobre. SOCRadar a trouvé sept serveurs exposés d'affiliés des rançongiciels INC et The Gentlemen, contenant Phantom, un cadre d'intrusion qui exécute les attaques via l'interface OpenCode et des modèles commerciaux appelés par OpenRouter. Les journaux comptent 8 257 messages d'IA sur 133 sessions, pour 23 920 dollars d'API.Report published October 20. SOCRadar found seven exposed servers belonging to affiliates of the INC and The Gentlemen ransomware, holding Phantom, an intrusion framework that runs attacks through the OpenCode interface and commercial models called via OpenRouter. The logs hold 8,257 AI messages across 133 sessions, for 23,920 dollars of API spend.

Le coût d'une campagne d'intrusion se lit désormais sur une facture d'API. Les refus des modèles étaient contournés en présentant le travail comme un test autorisé.The cost of an intrusion campaign now reads off an API bill. Model refusals were worked around by framing the work as an authorised test.
